# TabLink Boxlight deployment

Independent experimental browser receiver and code-pairing service for Boxlight Opera 65. This source lives on a dedicated branch. The main FourToCheckers branch is not modified.

Open the Render URL on the board, generate a code, then enter it on a sender device with browser screen-capture capability. **Android screen capture requires a separate native companion application.** Actual iPhone capture and Boxlight decoding are unverified. TURN is not configured by default; different networks may fall back to low-FPS JPEG streaming. The hosted service is a prototype; do not share sensitive or student data.
